# Mikan Website — Project Instructions

## Client brief (verbatim intent — do not reinterpret)
- **Corporate look.** Reference sites: macegroup.com, mercuryeng.com.
- **Hero MUST have a video background.** Not an SVG drawing. Not a gradient. A real
  `<video autoplay muted loop playsinline>` filling the hero with a dark overlay and
  text on top. If no footage exists yet, use a real video file as placeholder — never
  a line drawing.
- **Images throughout the page.** Every major section needs real photographic imagery.
  Flat colour blocks, bare grids and text-only sections are not acceptable.
- **Must look attractive and professional**, not minimal or sparse.

## Stack (fixed)
Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · npm
Dev server runs on **port 5188**.

## Brand
From `public/mikan-logo.png`:
- green `#00A651` · blue `#0072CE` · cyan `#29ABE2` · orange `#F7941D` · ember `#F04E23`
- Tagline: **Precision. Progress. Partnership.**
- Business: structural steel detailing, BIM/MEP, E&I design. Singapore entity + India delivery.
- Audience: main contractors / EPCs, steel fabricators, direct owners. NOT a recruitment site.

## How to work on this project
- **Analyse, then act.** Do not start building before the brief is understood.
- **Do not research or explore unnecessarily.** No web searches unless asked.
- **Do not poll, re-check or re-read** files that were just written.
- **Build what was asked for — not a reduced version of it.** If the ask is a video
  hero with images, do not substitute something simpler and explain why afterwards.
- If an asset is missing, use a realistic stand-in that matches the intended final
  form (video for video, photo for photo) and say clearly what to replace.
- Be precise and efficient. No filler commentary.
